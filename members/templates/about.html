Project Overview: E-Commerce Website with Shopping Cart and Payment Integration

Project Name: JodiEnterprise (or similar)

Purpose: To build a web-based e-commerce platform that allows registered users to browse products, add them to a shopping cart, manage the cart (add, edit quantity, remove items), and complete checkout using multiple payment methods.

Key Features

  • User Authentication:
    • Users can sign up with first name, last name, email, and password.
    • Login functionality with session-based authentication.
    • Logout clears session data.
    • Only logged-in users can access the cart and checkout.
  • Product Catalog:
    • Products are loaded from a JSON file (data.json) categorized by product type.
    • Users can view products with details such as name, price, and category.
    • Product page displays current cart count.
  • Shopping Cart:
    • Users can add products to the cart.
    • Cart supports updating quantities and removing items dynamically.
    • Shows individual item totals and a grand total.
    • Cart state is stored in the session using a custom Cart class.
  • Checkout & Payments:
    • Users can checkout once items are in the cart.
    • Multiple payment methods:
      • PayPal: Redirect option.
      • Mobile Wallet: Input phone number for payment.
      • Debit Card: Input card number, expiry, and CVV.
    • Payment selection dynamically displays the required input fields.
  • Frontend Design:
    • Built with Tailwind CSS for responsive and modern UI.
    • Dynamic interactions handled with vanilla JavaScript.
    • Cart updates, item removal, and payment selections happen without page reloads where possible.
  • Backend:
    • Built with Django framework.
    • Uses session-based cart storage.
    • Provides JSON APIs for add/update/remove cart actions.
    • Includes CSRF protection and login validation.
    • Handles error messages and success notifications with Django messages framework.

Optional/Planned Enhancements

  • Email notifications for successful purchases.
  • Integration with real payment gateways (PayPal SDK, Stripe, mobile wallets).
  • User order history/dashboard.
  • Admin panel for managing products and orders.

Summary

This project is essentially a full-stack e-commerce system where users can:

  • Browse products
  • Add them to a session-based cart
  • Modify quantities or remove items
  • Choose between multiple payment methods
  • Complete checkout with session handling and dynamic feedback

It combines Django backend, session management, JSON product data, and modern frontend interactivity using Tailwind and JavaScript.
